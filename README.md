## Overview

The [Titanic: Machine Learning from Disaster](https://www.kaggle.com/competitions/titanic) is one of Kaggle's most popular beginner competitions. The goal is to use passenger data (age, sex, ticket class, fare, etc.) to **predict which passengers survived** the sinking of the RMS Titanic on April 15, 1912.

This project walks through the full machine learning pipeline:
- Data exploration and cleaning
- Feature engineering and encoding
- Baseline modelling
- Multi-model cross-validation comparison
- Hyperparameter tuning with `RandomizedSearchCV`
- Final predictions submitted to Kaggle

---

## Dataset

The data is sourced directly from the [Kaggle Titanic competition](https://www.kaggle.com/competitions/titanic/data) and stored in the `data/` directory.

| File | Description |
|------|-------------|
| `data/train.csv` | 891 labelled passenger records used for training |
| `data/test.csv` | 418 unlabelled records used for generating predictions |
| `data/gender_submission.csv` | Kaggle's sample submission file |
| `data/bethuel_predictions.csv` | Final predictions generated by this project |

### Feature Descriptions

| Feature | Type | Description |
|---------|------|-------------|
| `PassengerId` | int | Unique passenger identifier |
| `Survived` | int (0/1) | Target variable — 0 = Did not survive, 1 = Survived |
| `Pclass` | int (1/2/3) | Ticket class (proxy for socioeconomic status) |
| `Name` | string | Passenger name *(dropped)* |
| `Sex` | string | Passenger sex → encoded to 0/1 |
| `Age` | float | Passenger age in years → missing values filled with median |
| `SibSp` | int | Number of siblings/spouses aboard |
| `Parch` | int | Number of parents/children aboard |
| `Ticket` | string | Ticket number *(dropped)* |
| `Fare` | float | Passenger fare |
| `Cabin` | string | Cabin number *(dropped — too many missing values)* |
| `Embarked` | string | Port of embarkation (C=Cherbourg, Q=Queenstown, S=Southampton) → one-hot encoded |

## Methodology

### 1. Exploratory Data Analysis

The `preprocess()` function provides a structured summary of any DataFrame:

- **Head** — first 10 rows
- **Info** — dtypes and non-null counts (used to detect missing values)
- **Numeric summary stats** — via `describe(include=['int','float'])`
- **Categorical summary stats** — via `describe(include=['str','object'])`

**Key findings:**
- `Age` had ~19% missing values in train and ~20% in test
- `Cabin` had ~77% missing values → dropped entirely
- `Embarked` had 2 missing values → filled with mode
- `Sex` and `Embarked` required encoding before modelling

---

### 2. Data Preprocessing

A reusable `datacleaner()` function was built to apply consistent preprocessing to both train and test sets:

```python
def datacleaner(dataframe):
    dataframe = dataframe.copy()

    # Drop high-noise / ID columns
    dataframe.drop(['Name', 'Ticket', 'Cabin'], axis=1, inplace=True)

    # Fill missing numeric values
    dataframe['Age'] = dataframe['Age'].fillna(dataframe['Age'].median())

    # Fill missing categorical values
    dataframe['Embarked'] = dataframe['Embarked'].fillna(dataframe['Embarked'].mode()[0])

    # Binary encode Sex
    dataframe['Sex'] = dataframe['Sex'].map({'male': 0, 'female': 1})

    # One-hot encode Embarked (drop_first to avoid multicollinearity)
    dataframe = pd.get_dummies(dataframe, columns=['Embarked'], drop_first=True)

    return dataframe
```

**Columns dropped:** `Name`, `Ticket`, `Cabin`

**Final feature set:** `PassengerId`, `Pclass`, `Sex`, `Age`, `SibSp`, `Parch`, `Fare`, `Embarked_Q`, `Embarked_S`

---

### 3. Model Selection via Cross-Validation

Six classifiers were compared using **10-fold Stratified K-Fold cross-validation** to ensure class balance across folds:

```python
models = {
    'Logistic Regression': LogisticRegression(max_iter=1000),
    'Decision Tree':       DecisionTreeClassifier(random_state=42),
    'Random Forest':       RandomForestClassifier(random_state=42),
    'Gradient Boosting':   GradientBoostingClassifier(random_state=42),
    'SVM':                 SVC(),
    'KNN':                 KNeighborsClassifier()
}
```

#### Cross-Validation Results (10-fold, stratified)

| Model | Accuracy | Precision | Recall | F1 Score |
|-------|----------|-----------|--------|----------|
| Logistic Regression | 0.787 | 0.734 | 0.703 | 0.715 |
| Decision Tree | 0.751 | 0.677 | 0.690 | 0.681 |
| **Random Forest** | **0.816** | **0.792** | 0.708 | 0.744 |
| **Gradient Boosting** | **0.820** | **0.809** | 0.699 | **0.748** |
| SVM | 0.658 | 0.827 | 0.147 | 0.245 |
| KNN | 0.616 | 0.502 | 0.334 | 0.399 |

> **Gradient Boosting** and **Random Forest** were the top performers. Random Forest was selected for tuning due to its robust ensemble characteristics and interpretability.

**Baseline (DummyClassifier — most_frequent strategy):** ~61.5% accuracy — all serious models meaningfully exceed this floor.

---

### 4. Hyperparameter Tuning

`RandomizedSearchCV` was used to tune `RandomForestClassifier` over **60 random combinations**, scored on F1 using the same 10-fold stratified CV:

```python
param_distributions = {
    'n_estimators':      [20, 50, 100, 150, 200],
    'max_depth':         [1, 2, 3, 4],
    'min_samples_split': [5, 10, 15, 20],
    'min_samples_leaf':  [2, 4, 6, 8],
    'max_features':      ['sqrt', 'log2']
}
```

**Best parameters found:**

| Parameter | Value |
|-----------|-------|
| `n_estimators` | 150 |
| `max_depth` | 4 |
| `min_samples_split` | 20 |
| `min_samples_leaf` | 2 |

---

### 5. Final Model & Predictions

The tuned `RandomForestClassifier` was retrained on the **full training set**, with features scaled via `StandardScaler`:

```python
proper_model = RandomForestClassifier(
    max_depth=4,
    min_samples_leaf=2,
    min_samples_split=20,
    n_estimators=150,
    random_state=42
)

scaler = StandardScaler()
```

## Installation & Setup

This project uses [**uv**](https://github.com/astral-sh/uv) for fast Python package management.

### Prerequisites

- Python >= 3.14
- `uv` installed — [installation guide](https://docs.astral.sh/uv/getting-started/installation/)

### Steps

```bash
# 1. Clone the repository
git clone <your-repo-url>
cd Titanic-ML

# 2. Create the virtual environment and install all dependencies
uv sync

# 3. Activate the virtual environment
# On Windows:
.venv\Scripts\activate
# On macOS/Linux:
source .venv/bin/activate
```
